# La furia del silencio

Landing estática para la reserva de entradas.

## Vista local

Abrí `index.html` en el navegador o usá cualquier servidor estático.

## Publicación en Vercel

Subí esta carpeta a un repositorio y conectalo con Vercel. No necesita comando
de compilación ni directorio de salida: es HTML, CSS y JavaScript estático.

Antes de publicar, añadí esta variable de entorno en Vercel:

- `RESERVATION_API_SECRET`: el valor privado `api_secret` de la pestaña
  Configuración de Google Sheets.
